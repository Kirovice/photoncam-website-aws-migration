## 线上交叉核对补充 / 公開サイトとの照合

结果：126/126 文件 HTTP 200 且逐字节一致，包括全部 50 HTML、72 JS、2 CSS、2 XML。中英文首页、教程、图库、介绍、隐私及订阅页面均包含在内。50 HTML 包含两份 404.html；直接请求 404.html 返回 200，不等于不存在的 URL 也返回 200，本次未验证不存在 URL 的行为。

結果：HTML 50、JS 72、CSS 2、XML 2 の計 126 ファイルがすべて HTTP 200、バイト単位一致。404.html への直接アクセス結果と、存在しない URL の HTTP ステータスは別事項。後者は未検証。

据此可将该 ZIP 的页面和程序资源作为当前线上迁移对照基线。线上 HTML 同样标记 Docusaurus 3.5.2。结合前次源码 static 与 ZIP 的 94 文件一致，已建立源码资源—ZIP—线上页面/程序的交叉证据，但不能证明当前源码提交的构建可复现性。
