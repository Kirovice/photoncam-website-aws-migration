## 线上交叉核对补充 / 公開サイトとの照合

用户提供成品地址：[中文首页](https://juniperphoton.dev/photoncam/zh-hans/)。本次以 HTTP GET 读取 ZIP 中 HTML、JS、CSS、XML 对应线上地址，将 index.html 映射到目录 URL，比较响应内容与 ZIP 解压内容的 SHA-256。逐文件结果与实际检查时间保存于 `线上与ZIP核对证据.json`。

利用者指定の公開サイトを HTTP GET で取得し、ZIP 内 HTML・JS・CSS・XML と SHA-256 を比較。index.html はディレクトリ URL に対応付けた。各ファイルの結果と実測日時は JSON 証拠に保存。

结果：126/126 文件 HTTP 200 且逐字节一致，包括全部 50 HTML、72 JS、2 CSS、2 XML。中英文首页、教程、图库、介绍、隐私及订阅页面均包含在内。50 HTML 包含两份 404.html；直接请求 404.html 返回 200，不等于不存在的 URL 也返回 200，本次未验证不存在 URL 的行为。

結果：HTML 50、JS 72、CSS 2、XML 2 の計 126 ファイルがすべて HTTP 200、バイト単位一致。404.html への直接アクセス結果と、存在しない URL の HTTP ステータスは別事項。後者は未検証。

据此可将该 ZIP 的页面和程序资源作为当前线上迁移对照基线。线上 HTML 同样标记 Docusaurus 3.5.2。结合前次源码 static 与 ZIP 的 94 文件一致，已建立源码资源—ZIP—线上页面/程序的交叉证据，但不能证明当前源码提交的构建可复现性。

ZIP のページ・プログラム資産は現行公開サイトとの比較基準にできる。公開 HTML の生成版も 3.5.2。前回の static 94 ファイル一致と合わせて関係を確認したが、現行ソースコミットの再ビルド成功を証明するものではない。

边界：未逐一下载线上图片比对，未进行浏览器视觉或交互验收，未证明线上不存在 ZIP 之外的额外页面。本次结果是静态文件一致性核对；AWS 迁移后仍需页面显示、语言切换、图库交互与深层链接验收。版本统一应考虑线上 3.5.2 基线，不直接认定清单 3.6.3 就是原站构建版本。

制約：公開画像の全件照合、ブラウザー表示・操作検証、ZIP 外ページの有無は未確認。AWS 移行後に画面・言語切替・ギャラリー操作・深いリンクを受入検証する。依存版の確定では公開版 3.5.2 を考慮し、3.6.3 を既存ビルド版と断定しない。
